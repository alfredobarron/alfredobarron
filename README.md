# Alfredo Barrón

Arquitecto de software en Monterrey, México. Llevo más de 15 años construyendo software para
empresas: sistemas web, apps para iOS y Android y la infraestructura en la nube que los sostiene.

Trabajo directamente con dueños de negocio y directores. Me cuentan cómo trabaja hoy su operación
(el punto A) y a dónde quieren llegar (el punto B); yo diseño, construyo y opero el sistema que
recorre ese tramo.
